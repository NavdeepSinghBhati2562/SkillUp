# DSA: Pattern-by-Pattern Problem List

About 130 problems grouped by pattern, in the order of the weekly tracker. Solve them in Java
and save solutions as `dsa/solutions/<pattern>/<ProblemName>.java`.

**For every problem:**
1. Spend 5 min clarifying and thinking of a brute force, and say its complexity out loud.
2. Spend up to 25 min on an optimal approach and code.
3. If stuck, read the solution, then write it yourself without looking.
4. Log it in [`log.md`](log.md). Anything marked ❌ gets re-solved 3 days later.

Resources: [NeetCode roadmap videos](https://neetcode.io/roadmap) for explanations,
[Tech Interview Handbook](https://www.techinterviewhandbook.org/algorithms/study-cheatsheet/) cheatsheets.

## Weeks 10–12: interview-mode practice
- 3 random mediums a day, timed (45 min for all three), with no pattern hints.
- Company-tagged lists on LeetCode for your top targets (premium is worth it for weeks 11–12).
- Re-solve everything marked ❌ in your log.

## Java essentials to have at your fingertips
`HashMap`, `HashSet`, `ArrayDeque` (stack and queue), `PriorityQueue` with a comparator,
`TreeMap` (`floorKey`/`ceilingKey`), `Arrays.sort` with lambdas, `StringBuilder`,
`Collections`, `int[]` vs `List<Integer>` conversions, and `Integer.MAX_VALUE` overflow traps.
